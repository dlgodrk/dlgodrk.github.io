# 셈셈 계산기 홍보·SEO 실행안

사이트: https://dlgodrk.github.io/ (GitHub Pages, 저장소 `dlgodrk/dlgodrk.github.io`)
목표: 하루 방문자 10,000명. 근거와 리서치는 `docs/research/seo-korea.md`.

## 1. 트래픽 가설

검색 점유율은 네이버 약 68%, 구글 약 27%, Bing 약 3%입니다(2026년 9~10월 표본). 그래서 네이버 노출이 가장 중요합니다.

| 유입 경로 | 노리는 검색어 예 | 페이지 수 |
|---|---|---|
| 연봉 실수령액 | "연봉 4200 실수령액", "연봉 실수령액 표" | 약 110 |
| 나이·띠 | "1990년생 나이", "90년생 띠" | 97 |
| 평수 | "84제곱미터 평수", "59㎡ 몇평" | 50 |
| 표준체중 | "키 170 표준체중" | 61 |
| 전역일 | "2025년 6월 입대 전역일" | 약 43 |
| 알바 월급 | "주 20시간 알바 월급" | 16 |
| 대출·예적금 | "1억 대출 이자", "1억 예금 이자" | 약 25 |
| 계산기 본 페이지 | "퇴직금 계산기", "실업급여 계산기", "만나이 계산기" 등 | 19+ |

계산기 본 페이지는 경쟁이 세서 상위 노출까지 수개월이 걸립니다. 반면 롱테일 페이지는 경쟁이 약해 먼저 유입이 생깁니다. 10,000명/일은 색인이 쌓이는 3~6개월 뒤를 목표로 잡는 것이 현실적입니다.

## 2. 검색엔진 등록 (배포 직후)

| 엔진 | 할 일 | 상태 |
|---|---|---|
| IndexNow (네이버·Bing·Yandex 공유) | `node scripts/indexnow.mjs` 로 전체 URL 제출. 키 파일은 사이트 루트에 자동 생성 | 자동화 완료 |
| 구글 서치 콘솔 | URL 접두어 속성 `https://dlgodrk.github.io/` 추가 → HTML 태그 인증 → `sitemap.xml` 제출 | 아래 3절 |
| 네이버 서치어드바이저 | 사이트 등록 → HTML 태그 인증 → 요청 > 사이트맵 제출(`/sitemap.xml`), RSS 제출(`/rss.xml`), 웹 페이지 수집 요청(주요 20개) | 아래 3절 |
| Bing 웹마스터 도구 | 구글 서치 콘솔에서 가져오기(Import) | 아래 3절 |
| 다음 웹마스터도구 | PIN 발급 → robots.txt 에 PIN 줄 추가 → 확인 | 선택 |

인증 코드는 `src/lib/site.ts` 의 `VERIFICATION` 기본값이나 GitHub 저장소 변수(`GOOGLE_SITE_VERIFICATION`, `NAVER_SITE_VERIFICATION`, `BING_SITE_VERIFICATION`)로 넣습니다. 넣은 뒤 다시 배포하면 메타 태그가 붙습니다.

## 3. 커뮤니티 공유 초안

아래 글은 **사용자 계정으로 올려야 하므로 직접 확인 후 게시**하세요. 커뮤니티마다 자기 홍보 규칙이 있어, 새 계정이 홍보 글만 올리면 삭제·차단될 수 있습니다.

### GeekNews (news.hada.io) — Show GN
- 규칙: 직접 만든, 지금 쓸 수 있는 것만. 제목 형식 "이름 - 핵심 기능". 댓글 피드백에 답해야 함. 새 계정은 1주일 뒤 링크 게시 가능.
- 제목: `셈셈 계산기 - 2026년 기준 연봉 실수령액·퇴직금·만 나이 계산기 모음`
- 본문:
  > 회원가입이나 광고 없이 바로 쓰는 생활 계산기 모음을 만들었습니다.
  > - 연봉 실수령액은 국세청 간이세액표 7,117칸 전부와 4대보험 공식 모의계산 결과에 맞춰 검증했습니다.
  > - 퇴직금은 고용노동부 계산기와 같은 반올림 규칙을 씁니다.
  > - 입력값은 브라우저에서만 계산하고, 결과는 링크로 공유됩니다.
  > - Next.js 정적 사이트라 GitHub Pages에서 돌아갑니다.
  >
  > 계산이 틀린 곳을 알려 주시면 바로 고치겠습니다.

### 디스콰이엇 (disquiet.io)
- 프로덕트 등록 후 메이커로그 작성. 제목: `월급 명세서처럼 보여 주는 계산기 사이트를 만들었어요`
- 본문 요지: 왜 만들었는지(광고 많은 계산기 사이트 불편), 검증 방식(공식 표와 대조 테스트), 디자인(명세서와 도장), 다음 계획.

### 클리앙 — 직접홍보 게시판 (일반 게시판 금지)
- 제목: `[직접홍보] 2026년 기준 연봉 실수령액·퇴직금 계산기 (무료, 가입 없음)`
- 본문: 위 GeekNews 본문을 존댓말로 줄이고, 광고·가입 없음과 검증 방식을 강조.

### 네이버 블로그 (자체 채널, 네이버 색인에 유리)
- 글 1: `2026년 연봉 실수령액 표 (2,000만원~1억원)` — 표 일부와 사이트 링크 1개. 같은 링크를 반복해서 넣지 않기.
- 글 2: `2026 최저임금 10,320원, 2027년 10,700원 — 알바 월급 계산법` — 주휴수당 공식 설명 + 링크.
- 글 3: `만 나이 계산법 정리 (띠, 학교 입학 연도까지)` — 출생연도 표 + 링크.

## 4. 수익화 전 결정할 것

- 광고(AdSense)는 `github.io` 하위 도메인으로는 승인받기 어렵습니다. 수익화하려면 개인 도메인(연 1~2만원대)을 사서 GitHub Pages에 연결하세요. 연결하면 기존 주소는 GitHub가 새 도메인으로 자동 이동시킵니다.
- 도메인을 바꾸면 `NEXT_PUBLIC_SITE_URL` 을 새 주소로 바꾸고, 서치 콘솔·서치어드바이저에 새 사이트를 등록한 뒤 IndexNow를 다시 실행합니다.
