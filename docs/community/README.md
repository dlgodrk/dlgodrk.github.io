## 모든 글에 지키는 원칙

1. **만든 사람임을 첫 문단에 밝힙니다.** "제가 만든", "직접 만든", "만든 사람입니다"처럼 내가 만들었다는 사실이 드러나는 문장을 반드시 넣습니다. 질문에 먼저 답하는 댓글(뽐뿌 예시)만은 링크를 꺼내는 문장에서 밝힙니다. 지나가던 사용자인 척하지 않습니다. 초안의 "혼자 만든"은 운영자 한 사람이 만들었다는 전제로 썼습니다. 함께 만든 사람이 있으면 "저희가 만든"으로 고치세요.
   **누가 무엇을 했는지도 사실대로 씁니다.** 아래 문장은 올리기 전에 실제와 맞게 고치세요.
   - "AI 코딩 도구를 많이 썼다": GeekNews 본문, 클리앙 초안 B, 디스콰이엇 메이커로그 1편.
   - 간이세액표 역산 "AI 코딩 도구로 표를 거꾸로 맞춰 보니": 클리앙 초안 B 1번 단락, 디스콰이엇 메이커로그 2편 [막혔던 곳]. 역산은 `docs/research/withholding-2026.md` 첫머리에 적힌 대로 AI 리서치 에이전트가 했습니다. 운영자가 직접 맞춰 본 것이 아니면 "제가 맞춰 본", "제가 찾아낸"처럼 쓰지 않습니다.
   - 디스콰이엇 메이커로그 2편 [표를 계산식으로 다시 만들어 본 이유]의 동기 설명이 실제와 다르면 고치세요.
   - 짧은 글(클리앙 초안 A, 디스콰이엇 소개 글, X/Threads)에는 AI 문장이 없습니다. 댓글에서 물으면 사실대로 답합니다.
2. **계정은 하나만 씁니다.** 다른 계정이나 지인 계정으로 추천, 댓글, "써 보니 좋네요" 같은 후기를 달지 않습니다. 지인에게 추천이나 댓글을 부탁하지 않습니다.
3. **과장하지 않습니다.** 아래 "확인된 사실"에 있는 숫자와 표현만 씁니다.
4. **같은 글을 복사해 여러 곳에 붙이지 않습니다.** 커뮤니티마다 글을 따로 썼습니다. 클리앙 개발한당 공지는 복사·붙여넣기 홍보를 권하지 않습니다.
5. **하루에 한 곳씩** 올리고, 올린 날에는 댓글에 답할 시간을 비워 둡니다. GeekNews는 질문과 피드백에 답하는 것이 게시 조건입니다.
6. **틀렸다는 지적은 고맙게 받고 고칩니다.** 고친 내용은 댓글로 알립니다.

### 써도 되는 표현

- "간이세액표 7,117칸 전부와 비교하는 테스트를 통과합니다."
- "4대보험은 공식 모의계산 23개 금액과 원 단위로 대조해 봤습니다(초고소득 구간 1곳은 10원 차이)."
- "계산은 브라우저에서만 하고, 입력값을 저장하는 서버는 없습니다. 다만 결과 공유를 위해 입력값이 링크(URL)에 담깁니다."
- "자동 테스트가 1,000개 넘게 있고, 통과해야 배포됩니다."
- "결과는 추정치이고, 회사 규정에 따라 실제 금액은 다를 수 있습니다."

### 쓰면 안 되는 표현

- "가장 정확한", "100% 정확", "오차 없음", "완벽" — 검증한 것은 간이세액표, 4대보험, 퇴직금 계산 방식이고 30개 계산기 전부가 아닙니다.
- "국세청 공식", "정부 인증", "국세청 계산기와 같은 결과" — 공식 표와 기관 모의계산 결과에 맞췄을 뿐, 기관의 인증을 받은 것이 아닙니다. 홈택스 계산기와는 비교하지 않았습니다.
- "연말정산 결과와 같다" — 간이세액표는 매달 떼는 원천징수 기준입니다.
- "많은 분이 쓰고 계신", "반응이 좋은" — 방문자 통계가 없습니다.
- "앞으로도 광고 없음" — 광고를 붙일 수 있다고 방침에 적혀 있습니다. "지금은 광고가 없습니다"까지만 씁니다.
- "오픈소스" — 저장소에 라이선스 파일이 없습니다. 라이선스를 정하기 전에는 쓰지 않습니다.
- "4대보험 23개 금액 전부 일치", "공식 모의계산과 똑같다" — 23개 중 1개는 10원 다릅니다(위 표).
- "입력값을 서버로 보내지 않는다" — 입력값이 URL에 담겨 페이지 요청과 함께 GitHub Pages로 갑니다(위 표).
