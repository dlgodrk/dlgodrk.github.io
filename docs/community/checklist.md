# 커뮤니티별 자기 홍보 규칙 체크리스트

기본 출처: `docs/research/seo-korea.md` (2026-10-09 조사). "2026-10-09 재확인"이라고 적은 항목은 이 초안을 쓰면서 해당 페이지를 다시 읽고 보탠 내용입니다.
규칙은 바뀝니다. 올리기 직전에 각 커뮤니티의 공지와 이용규칙을 한 번 더 읽으세요.

## 공통 (모든 커뮤니티)

- [ ] 첫 문단에 내가 만들었다는 사실이 드러나 있다 (예: "제가 만든", "직접 만든", "만든 사람입니다", "만든 메이커입니다"). 질문에 먼저 답하는 댓글(뽐뿌 예시)만은 링크를 꺼내는 문장에서 "제가 직접 만든"으로 밝힌다.
- [ ] 누가 무엇을 했는지 사실대로 썼다. AI 도구를 쓴 작업(간이세액표 역산 등)을 "제가 맞춰 본"처럼 내가 직접 한 것으로 쓰지 않았다 ([README.md](README.md) 원칙 1).
- [ ] 내 계정 하나로만 올린다. 다른 계정, 지인 계정으로 추천·댓글·후기를 달지 않는다.
- [ ] 지인에게 추천(업보트), 좋아요, 댓글을 부탁하지 않는다.
- [ ] 숫자와 표현이 [README.md](README.md)의 "확인된 사실"과 같다. 계산기 수, 테스트 수를 올리기 직전에 다시 셌다.
- [ ] "가장 정확한", "공식 인증", "100%" 같은 과장 표현이 없다.
- [ ] 다른 커뮤니티 글을 그대로 복사하지 않았다.
- [ ] 단축 URL이나 중간 페이지 없이 https://dlgodrk.github.io/ 를 그대로 쓴다.
- [ ] 올린 뒤 하루 동안 댓글에 답할 수 있다.
- [ ] 사이트에 광고를 붙였다면, 글의 "광고 없음" 문장을 고치거나 지웠다.

## GeekNews (news.hada.io) — Show GN

출처: seo-korea.md `promo_geeknews_show_gn` (high). https://news.hada.io/guidelines , https://news.hada.io/blog/show (2026-10-09 재확인)

- [ ] 내가 만들었거나 만드는 데 참여한 것이다.
- [ ] 지금 바로 쓸 수 있다. 블로그 글, 랜딩·사전 등록 페이지, 뉴스레터, 유튜브 링크는 Show GN에 올릴 수 없다.
- [ ] 가입하거나 이메일을 넣지 않고 써 볼 수 있다 (권장 사항, 셈도장은 해당).
- [ ] 게시 유형을 **Show**로 고른다. 직접 만든 것을 일반 뉴스로 올리면 삭제될 수 있다.
- [ ] 제목은 `서비스명 - 핵심 기능` 형식이다. "Show GN:"은 자동으로 붙으니 직접 쓰지 않는다. 동기, 성과 수치, 홍보 문구는 제목이 아니라 본문에 쓴다.
- [ ] 본문에 무엇인지, 누가 어떻게 쓰는지, 기존과 무엇이 다른지, 왜 만들었는지, 어떤 피드백을 원하는지가 있다. 내가 만들었다고 밝힌다. 판매 문구 대신 사실만 쓴다.
- [ ] 본문을 댓글에 다시 붙이지 않는다.
- [ ] 가입 후 1주일이 지난 계정이다 (새 계정은 1주일 뒤부터 링크 게시 가능).
- [ ] 같은 프로젝트를 정해진 기간 안에 다시 올리지 않는다. 큰 업데이트나 URL 변경도 예외가 아니다. 기간은 공개되어 있지 않다.
- [ ] 여러 프로젝트를 연달아 올리지 않는다.
- [ ] 질문과 피드백에 직접 답한다 (게시 조건).
- 위반하면 글 삭제, 이후 게시 제한, ID·IP·도메인 단위 제재가 있을 수 있다.

## 클리앙 (clien.net)

출처: seo-korea.md `promo_clien_rules` (high). 이용규칙 https://www.clien.net/service/board/rule/10707403 (2026-05-18 개정), 개발한당 공지 https://www.clien.net/service/board/cm_app/15199283 (2024-07-03 수정), 직접홍보 이용안내 https://www.clien.net/service/board/rule/10707409 (2020-04-16 수정, 2026-10-09 재확인)

이용규칙 (사이트 전체)
- [ ] 일반 회원인 척하며 홍보하지 않는다 (2-2).
- [ ] 바이럴, 블로그·영상·앱의 전문적인 홍보를 일반 게시판에 하지 않는다 (2-3).
- [ ] 추천인 코드, 이미지 링크 목적의 반복 게시를 하지 않는다 (2-4).
- [ ] 후원이나 금전을 요청하지 않는다 (2-5).
- [ ] 게시판 성격에 맞는 곳에 올린다 (8-1).

직접홍보 게시판 (`/service/board/hongbo`)
- [ ] **기업회원만 쓸 수 있다.** 일반회원은 기업회원으로 따로 가입해야 하고, 기업회원은 일반 게시판 이용이 제한된다.
- [ ] **유료다.** 7일 44,000원, 15일 66,000원, 30일 99,000원, 60일 198,000원 (2020-04-16 안내 기준, 바뀌었을 수 있음). 신청서 → 입금 → 관리자 승인.
- [ ] 새 글은 하루에 한 번만.
- [ ] 신청한 상품만 홍보한다.
- [ ] 제목에 특수문자나 자극적인 표현을 쓰지 않는다 (처음 1회 주의 후 제한).
- [ ] 다른 게시판에서 회원인 척 홍보하거나, 내 글에 회원인 척 댓글을 달지 않는다 (글 전부 삭제, 아이디 강등, 환불 없음).
- [ ] 글쓰기 전에 이메일 인증을 마쳤다.

개발한당 소모임 (`/service/board/cm_app`)
- [ ] 클리앙에서 이미 활동 이력이 있는 계정이다. 첫 글이 홍보이거나 홍보만 하는 계정은 예고 없이 삭제될 수 있다.
- [ ] 평소 다른 사람 글에도 댓글을 다는 등 활동하고 있다.
- [ ] 홍보 문구를 그대로 붙이지 않고, 만들면서 겪은 내용과 내 의견을 담았다.
- [ ] 수익으로 이어지는 링크가 없다. **사이트에 광고를 붙였다면 개발한당에 링크를 올리지 않는다.**

## 디스콰이엇 (disquiet.io)

출처: seo-korea.md `promo_disquiet` (medium). https://disquiet.io/ (2026-10-09 재확인)

- [ ] 로그인한 내 계정으로 프로덕트를 등록하고 메이커로 나를 지정한다.
- [ ] 홍보 규칙과 인기 프로덕트 순위 기준은 공개된 페이지에서 찾지 못했다. 등록 화면과 공지(`/announcement`)에 안내가 있으면 그것을 따른다.
- [ ] 좋아요나 댓글을 품앗이로 부탁하지 않는다 (공통 원칙).
- [ ] 메이커로그는 홍보 문구보다 만든 과정과 배운 점 위주로 쓴다.

## 뽐뿌 (ppomppu.co.kr)

출처: seo-korea.md `promo_ppomppu_rules` (low)

- 공식 자기 홍보 규칙을 찾지 못했다. 자유게시판에 홍보 글을 올리는 것은 권장하지 않는다. 이유와 대안은 [ppomppu.md](ppomppu.md).
- [ ] 그래도 쓴다면, 올릴 게시판의 고정 공지를 먼저 읽었다.
- [ ] 활동 이력이 있는 계정이고, 누군가의 실제 질문에 답하는 댓글로만 쓴다. 만든 사람이라고 밝힌다.

## X, Threads

seo-korea.md에는 X와 Threads 항목이 없습니다. 아래는 공통 원칙을 이 채널에 적용한 것입니다.

- [ ] 내 계정 프로필이나 글에 만든 사람이라고 드러나 있다.
- [ ] 같은 글을 여러 계정이나 짧은 간격으로 반복해 올리지 않는다.
- [ ] 관련 없는 인기 해시태그나 다른 사람 글 답글에 링크를 붙이지 않는다.

## 그 밖의 채널 (seo-korea.md 요약, 이번 초안 대상 아님)

- 디시인사이드 (`promo_dcinside_rules`, medium): 사이트 전체 규칙은 없고 갤러리마다 다르다. 예를 들어 데스크탑 마이너 갤러리는 명백한 상업 광고·홍보를 중대 위반으로 보고 경고 없이 30일 차단이나 영구 차단할 수 있다. 위험이 높으니 고정 공지가 허용하는 곳에서, 질문에 대한 답으로만 쓴다.
- 카카오톡 오픈채팅 (`promo_kakao_openchat`, medium): 원하지 않는 사람에게 하는 홍보는 이용 제한 사유이고 신고로 제재된다. 방장이 링크를 허용한 방에서, 질문에 답할 때만 쓴다.
- Reddit (`promo_reddit`, low): 자기 홍보는 활동의 10% 정도로 유지하는 것이 일반적인 기준이다. 영어권 이용자가 많아 한국 세금·급여 계산기와 맞지 않는다.
- 네이버 블로그·티스토리·카페·지식iN (`promo_owned_channels`, low): 같은 광고 링크를 반복하면 제한될 수 있다. 정보 글을 쓰고 계산기를 출처로 한 번 링크하는 방식이 가장 안전하다. 지식iN 마케팅 답변은 제한된 사례가 있다.
