# 클리앙 초안 — 직접홍보 게시판 (+ 개발한당 대안)

## 먼저 확인할 사실 (2026-10-09 재확인)

`docs/PROMOTION.md`는 직접홍보 게시판을 무료 게시판처럼 적었지만, 클리앙의 "직접홍보 게시판 이용안내"(2020-04-16 수정)를 다시 읽어 보니 다음과 같습니다.

- 직접홍보 게시판은 **기업회원만** 글을 쓸 수 있습니다. 일반회원은 기업회원으로 따로 가입해야 하고, 기업회원은 일반 게시판 이용이 제한됩니다.
- **유료**입니다. 7일 44,000원, 15일 66,000원, 30일 99,000원, 60일 198,000원이고, 신청서 작성 → 입금 → 관리자 승인 순서입니다. 승인된 글은 기간 동안 대부분의 게시판 위쪽에 노출됩니다.
- 새 글은 하루 한 번, 신청한 상품만, 제목에 특수문자나 자극적인 표현 없이 써야 합니다.

그래서 길은 두 가지입니다.

| 선택 | 조건 | 이 파일의 초안 |
|---|---|---|
| A. 직접홍보 게시판 | 기업회원 가입, 비용 지불. 무료 개인 프로젝트에는 비용 대비 효과를 따져 보세요 | 초안 A |
| B. 개발한당 소모임 | **이미 클리앙에서 활동 이력이 있는 개인 계정**만. 첫 글이 홍보이거나 홍보만 하는 계정은 예고 없이 삭제될 수 있음. 수익 링크 금지라서 **사이트에 광고가 없을 때만** | 초안 B |

계정 이력과 관계없이 일반 게시판(모두의공원, 사용기 등)에 홍보 글을 올리는 것은 이용규칙 2-3(전문적인 홍보), 8-1(게시판 성격)에 걸리고, 만든 사람임을 숨기면 2-2(회원 가장 홍보)에도 걸리므로 하지 않습니다.

규칙 전체는 [checklist.md](checklist.md)의 클리앙 항목을 보세요.

## 초안 A — 직접홍보 게시판

### 제목

```
2026년 기준 연봉 실수령액, 퇴직금 계산기 사이트를 만들었습니다
```

이용안내에 따라 제목에 대괄호, 별표 같은 특수문자와 "최고", "무조건" 같은 자극적인 표현을 넣지 않았습니다.

### 본문

```
안녕하세요. 셈도장 계산기를 만든 사람입니다. 혼자 만든 무료 계산기 사이트를 소개합니다.

https://dlgodrk.github.io/

연봉 실수령액, 4대보험, 퇴직금, 실업급여, 연말정산, 시급과 주휴수당, 만 나이, 평수, 대출 이자, 전역일 등 생활에서 자주 하는 계산 30가지를 모았습니다. 회원가입이나 앱 설치 없이 바로 쓸 수 있고, 지금은 광고도 없습니다.

어떤 점에 신경 썼는지 말씀드리면

1. 2026년 기준 숫자를 공식 자료와 맞춰 봤습니다.
 - 매달 떼는 소득세는 소득세법 시행령의 근로소득 간이세액표(2026년 2월 개정) 7,117칸 전부와 같은 값이 나오는지 테스트합니다.
 - 4대보험은 4대사회보험 정보연계센터 공식 모의계산에 23개 금액을 넣어 본 결과와 원 단위로 대조해 봤습니다(초고소득 구간 1곳은 10원 차이).
 - 퇴직금은 고용노동부 퇴직금 계산기와 같은 계산 방식을 따릅니다.
2. 결과를 급여명세서처럼 항목별로 보여 드립니다. 국민연금, 건강보험, 장기요양, 고용보험, 소득세가 각각 얼마인지 볼 수 있습니다.
3. 계산은 브라우저에서만 하고, 입력한 연봉이나 생년월일을 저장하는 서버는 없습니다. 다만 결과를 링크로 공유할 수 있도록 입력값이 링크(URL)에 담깁니다.
4. 계산기마다 아래쪽에 계산 방법과 기준, 출처를 적어 두었습니다.

다만 결과는 추정치입니다. 회사의 비과세 항목이나 상여 지급 방식, 부양가족 수에 따라 실제 금액은 달라질 수 있고, 연말정산으로 확정되는 세금과도 다릅니다.

계산이 실제 급여명세서와 다르거나 불편한 점이 있으면 댓글로 알려 주세요. 확인해서 고치겠습니다.
```

## 초안 B — 개발한당 소모임 (활동 이력이 있는 계정일 때만)

개발한당 공지는 홍보 문구를 그대로 붙이지 말고 내 의견과 내용을 담으라고 합니다. 그래서 초안 A와 다르게, 만들면서 겪은 일 위주로 썼습니다.

### 제목

```
간이세액표 7,117칸을 코드로 재현해 본 계산기 사이트를 만들었습니다
```

### 본문

```
개발한당에 처음으로 제 작업을 올려 봅니다. 제가 혼자 만든 생활 계산기 사이트입니다.

https://dlgodrk.github.io/

연봉 실수령액, 퇴직금, 실업급여, 만 나이 같은 계산기 30개를 모았고, 회원가입이나 광고 없이 쓸 수 있습니다. 만들면서 재미있었던 점 몇 가지를 나눠 봅니다.

1. 근로소득 간이세액표는 그냥 세율표가 아니었습니다.
소득세법 시행령 별표2(2026.2.27 개정)는 647행 x 11열, 7,117칸짜리 표입니다. 표를 통째로 넣는 대신 계산식으로 다시 만들어 보려고 했는데, 현행 근로소득세액공제 한도나 다른 국민연금 상한값을 넣으면 수백에서 수천 칸이 틀렸습니다. AI 코딩 도구로 표를 거꾸로 맞춰 보니 국민연금 4.5%, 기준소득월액 상한 449만원 같은 예전 기준을 넣어야 7,117칸이 전부 맞았습니다. 공식 문서에 나온 산식이 아니라 표에서 거꾸로 추정한 것이라, 테스트로 7,117칸 전부를 매번 비교하고 있습니다.

2. 4대보험은 공식 모의계산과 원 단위로 대조했습니다.
4대사회보험 정보연계센터(4insure.or.kr) 모의계산에 23개 금액을 넣어 받은 결과를 테스트 데이터로 넣었습니다. 국민연금은 기준소득월액의 천원 미만을 자른 뒤 근로자 몫에서 10원 미만을 자르는데, 기준소득월액의 천원 미만 절사를 빠뜨리면 수십 원까지 어긋납니다(예: 월 3,001,500원이면 142,540원이어야 하는데 142,570원이 나옵니다). 월 보수 약 1억 2,773만원이 넘는 구간에서만 고시된 건강보험료 상한을 따르느라 공식 모의계산과 10원 다르고, 이유는 코드에 적어 두었습니다.

3. 부동소수점도 한 번 걸렸습니다.
자바스크립트에서 3,000,000 x 0.009가 26,999.999...가 되어서, 그대로 10원 절사하면 고용보험료가 27,000원이 아니라 26,990원이 됩니다. 요율을 정수로 바꿔 계산하는 쪽으로 정리했습니다.

스택은 Next.js 16 정적 내보내기, React 19, TypeScript, Tailwind CSS 4, Vitest이고 GitHub Pages에 올렸습니다. 서버가 없어서 입력값은 브라우저에서만 계산합니다. 자동 테스트가 1,000개 넘게 있고, GitHub Actions에서 통과해야 배포됩니다. 개발에는 AI 코딩 도구를 많이 썼고, 그래서 숫자 검증에 시간을 더 들였습니다.

결과는 추정치라 회사 규정에 따라 실제 금액과 다를 수 있습니다. 급여명세서와 다르게 나오는 경우가 있으면 넣은 값과 함께 알려 주세요. 확인해서 고치겠습니다.
```

### 초안 B를 올리기 전에

- 이 계정으로 개발한당이나 다른 게시판에서 활동한 이력이 있는지 확인하세요. 없다면 초안 B를 올리지 않습니다. 홍보를 위해 일부러 활동 이력을 만드는 것도 하지 않습니다.
- "AI 코딩 도구를 많이 썼고" 문장은 실제 개발 방식과 맞게 고치세요.
- 1번 단락의 "AI 코딩 도구로 표를 거꾸로 맞춰 보니"도 실제와 맞게 고치세요. 간이세액표 역산은 `docs/research/withholding-2026.md` 첫머리에 적힌 대로 AI 리서치 에이전트가 했습니다. 운영자가 직접 맞춰 본 것이 아니면 "제가 맞춰 본"처럼 내가 찾아낸 것으로 읽히게 쓰지 않습니다.
- 사이트에 광고를 붙였다면 초안 B는 올리지 않습니다 (개발한당 공지: 수익으로 이어지는 링크 금지).
