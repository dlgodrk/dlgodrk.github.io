## 2. 메이커로그 1편 — 출시 (프로덕트 등록 당일)

### 제목

```
월급 명세서처럼 보여 주는 계산기 사이트를 만들었어요
```

### 본문

```
셈도장 계산기를 만든 메이커입니다. 혼자 만든 생활 계산기 사이트를 오늘 프로덕트로 등록했어요.
https://dlgodrk.github.io/

[왜 만들었나]
연봉 실수령액이나 퇴직금을 검색하면 계산기는 많은데, 같은 값을 넣어도 결과가 조금씩 달랐어요. 어떤 요율과 반올림 규칙을 썼는지, 언제 기준인지 적힌 곳도 드물었고요. 2026년에는 간이세액표의 자녀 공제 금액(3월)과 국민연금 상한(7월)이 해 중간에 바뀌었고, 11월분부터는 장기요양보험료 계산 비율도 바뀌어요. 같은 해 안에서도 기준이 몇 번씩 달라지니 더 헷갈렸어요. 그래서 "공식 자료와 숫자가 맞는지 테스트로 확인하는 계산기"를 목표로 잡았어요.

[어떻게 검증했나]
- 간이세액표: 소득세법 시행령 별표2의 7,117칸(647행 x 11열)을 계산식으로 다시 만들고, 7,117칸 전부와 비교하는 테스트를 통과시켰어요.
- 4대보험: 4insure.or.kr 공식 모의계산에 23개 금액을 넣고 나온 근로자 부담분을 테스트 데이터로 넣었어요. 월 보수 약 1억 2,773만원을 넘는 구간 한 곳만 고시된 상한을 따르느라 10원 차이가 나요.
- 퇴직금: 고용노동부 퇴직금 계산기와 같은 계산 방식을 따랐어요.
- 자동 테스트가 1,000개 넘게 있고, 통과해야 배포돼요.

[디자인]
계산 결과를 숫자 하나로 끝내지 않고, 급여명세서처럼 항목을 한 줄씩 보여 줘요. 국민연금, 건강보험, 장기요양, 고용보험, 소득세가 각각 얼마인지 보이고, 맨 위 핵심 금액에는 "실수령", "만나이" 같은 빨간 도장을 찍었어요. 사용자의 4분의 3쯤은 휴대폰으로 볼 거라고 보고 모바일 화면을 먼저 맞췄어요.

[만든 방식]
Next.js 16 정적 사이트로 만들어 GitHub Pages에 올렸어요. 서버가 없어서 입력값은 브라우저에서만 계산하고, 입력값은 링크에 담겨서 결과를 그대로 공유할 수 있어요. 개발에는 AI 코딩 도구를 많이 썼고, 그만큼 숫자 검증에 시간을 들였어요.

[다음에 할 일]
- 2027년 건강보험료율 고시와 장기요양·고용보험 요율, 간이세액표가 나오면 2027년 예상치를 확정값으로 바꾸기
```

### 1편을 올리기 전에

- "사용자의 4분의 3쯤은 휴대폰"은 실제 방문 통계가 아니라 `docs/CONVENTIONS.md`의 가정(약 75% 모바일)입니다. 그래서 "볼 거라고 보고"라고 썼습니다. 통계가 생기면 실제 숫자로 바꾸세요.
- 2027년 최저임금 10,700원은 사이트에 이미 들어 있습니다(최저임금 계산기, 2027년부터 시급 계산기). 그래서 할 일에 넣지 않았습니다.
- 2027년 보험료율은 일부가 아직 예상치라 글에 숫자를 쓰지 않았습니다. 2026-10-09 기준으로 국민연금 근로자 5.0%는 법으로 정해졌지만, 건강보험료율 7.19% 동결은 의결만 되고 고시 전이며, 장기요양·고용보험 요율과 간이세액표는 정해지지 않았습니다(`docs/CONVENTIONS.md`의 2027 예상 규칙). 올리기 전에 모두 확정되어 사이트에 반영했다면 이 할 일을 지우세요.
- [왜 만들었나]의 "11월분부터는 장기요양보험료 계산 비율도 바뀌어요"는 2026년 11월 전에 올린다는 전제입니다. 11월 이후에 올리면 "11월분부터 장기요양보험료 계산 비율도 바뀌어서"처럼 과거형으로 고치세요.
- "5월 종합소득세 시즌에 맞춘 계산기 검토"는 계획이 없어졌다면 지우세요. 하지 않을 일을 약속하지 않습니다.
- "AI 코딩 도구" 문장은 실제 개발 방식과 맞게 고치세요.

## 3. 메이커로그 2편 — 기술 기록 (1~2주 뒤)

홍보보다 배운 점을 나누는 글입니다. GeekNews나 디스콰이엇에서 받은 피드백을 고친 내용이 있으면 마지막 단락에 덧붙이세요.

### 제목

```
간이세액표 7,117칸을 계산식으로 재현하면서 알게 된 것
```

### 본문

```
셈도장 계산기를 만들고 있는 메이커입니다. 연봉 실수령액 계산기를 만들면서 근로소득 간이세액표를 계산식으로 재현해 본 기록을 남겨요.

[간이세액표가 뭔가요]
회사가 매달 월급에서 소득세를 떼는 기준표예요. 소득세법 시행령 별표2에 있고, 월급 구간 647줄과 공제대상가족 1~11명 열로 7,117칸이에요. 2026년 2월 27일 개정으로 바뀐 것은 8~20세 자녀 공제 금액뿐이고 본문 숫자는 2024년 표와 같았어요.

[표를 계산식으로 다시 만들어 본 이유]
7,117칸을 데이터로 넣어도 계산은 돼요. 그래도 계산식으로 다시 만들어 본 건, 표가 어떤 규칙으로 만들어졌는지 알아야 각 숫자가 어디서 나왔는지 설명할 수 있고, 지금 법과 어디가 다른지도 보이기 때문이에요. 그래서 소득세법의 근로소득공제와 기본세율, 표 주석에 있는 기본공제(1인당 150만원)와 특별공제 산식, 그리고 근로소득세액공제를 차례로 적용해 각 칸을 계산하고, 결과를 공식 표 7,117칸과 비교했어요. 사이트 코드에는 7,117칸짜리 표 대신 이 계산식이 들어가고, 공식 표는 테스트 데이터로만 써요. 월급 1,000만원 초과 구간은 별표에 적힌 산식을 그대로 옮겼어요.

[막혔던 곳]
산식에 현행 법 값을 그대로 넣으면 수백에서 수천 칸이 어긋났어요. AI 코딩 도구로 표를 거꾸로 맞춰 보니, 표 안에 이런 예전 기준이 들어 있어야 7,117칸이 모두 맞았어요.
- 연금보험료공제: 국민연금 4.5%, 기준소득월액 상한 449만원
- 근로소득세액공제: 현행 소득세법과 다른 예전 한도
이 두 값은 공식 문서에 나온 것이 아니라 표에서 거꾸로 추정한 거예요. 그래서 추정이 틀어지지 않도록 7,117칸 전부를 매번 테스트로 비교해요.

나머지 계산 방식은 이래요. 각 칸은 그 구간 가운데 금액 x 12를 연봉으로 보고 계산한 뒤 12로 나눠 10원 미만을 버리고, 1,000원 미만은 소득세법 제86조의 소액부징수에 따라 0원이에요.

[작은 함정]
- 많은 칸이 정확히 10원 단위에 떨어져서, 부동소수점으로 계산하면 아주 조금 모자란 값이 나와 10원이 깎이는 경우가 생겨요. 정수 연산이나 아주 작은 보정값이 필요해요.
- 8~20세 자녀 공제 금액은 2026년 3월 1일 이후 원천징수분부터 바뀌었어요(1명 20,830원, 2명 45,830원). 지금도 예전 금액(12,500원, 29,160원)을 쓰는 계산기가 있어요.

간이세액표는 매달 떼는 금액의 기준일 뿐이라, 1년 세금은 연말정산에서 확정돼요. 계산 방법과 출처는 사이트의 연봉 실수령액 계산기 아래쪽에 정리해 두었어요.
https://dlgodrk.github.io/salary/

틀린 부분이 있으면 알려 주세요.
```
